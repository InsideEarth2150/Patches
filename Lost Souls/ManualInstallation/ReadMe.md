## **Earth 2150: Lost Souls - Multiplayer**
*Version 2.2.2.6* - Multiplayer

InsideEarth - Community Discord Server: https://discord.gg/yxtzdUZ

## Installation
Recommended way to install the patch is by using one of the installers. If you cannot use the installer, follow the steps below to successfully install the 2.2.2.6 update.

0. You may want to backup your game directory.
1. Remove the following files (if exist):
- `dsound.dll`
- `Modules/*.ieo`
- `WDFiles/Language2*.wd`
- `WDFiles/Update2*.wd`
- `WDFiles/IeoArena_v*.wd`
2. Extract the `ls_mp-2226.zip` directory into your game folder and override all files.
3. Remove unnecessary `Language2226LS__.wd`language files from WDFiles (leave only the one that matches your game version - de/en/fr/pl/ru)
4. Verify version by:
- running the game
- checking if main menu shows 2.2.2.6 version in both bottom left and bottom right corners

The manual installation does not configure Windows Firewall, DirectPlay or the InsideEARTH VPN (the installer does). Use the IE Toolbox (MP setup) for that: https://github.com/InsideEarth2150/Files/tree/main/Tools/toolbox
